- Recompensa fixa por partida: R$ 1 milhão (sem opções para alterar o valor).
- O dinheiro aparece com nomes de grandezas (mil, milhão, bilhão, trilhão, quadrilhão e quintilhão), em vez de uma sequência enorme de zeros.
- Treinamento com opção de comprar o máximo que o saldo permitir, calculado sem travar o navegador.

- Lobby premium e compatibilidade com o progresso local já salvo no navegador.
